# 일본어 용어집

화면마다 같은 말을 다르게 옮기지 않도록, 반복해서 나오는 말의 일본어 표기를 여기 한 곳에 둔다. 새 화면을 번역할 때 먼저 이 표를 보고, 표에 없는 말이 여러 화면에 나오면 근거와 함께 표에 더한다.

근거는 실제 일본어 서비스의 표기다. 스픽은 [일본 App Store 페이지](https://apps.apple.com/jp/app/id1286609883), 듀오링고는 일본 언론 보도([PR TIMES](https://prtimes.jp/main/html/rd/p/000000092.000069537.html))에서 확인했다.

## 말투

- 앱 문구는 です・ます체(존댓말)로 쓴다. 한국어 「~해요」와 같은 높이다.
- 느낌표·물음표는 전각(！？)으로 쓴다.
- 스몰톡은 スモールトーク로 쓴다. 폰 화면 속 데모 제목처럼 칸이 좁아 안 들어가면 会話로 대신한다(「テディと会話」).
- 이름 뒤 조사는 문구 안에 둔다. 한국어 「{name}와」처럼 받침에 따라 갈리는 조사를 코드에서 붙이지 않는다. 「님」은 さん으로 쓴다.
