# 햅틱(진동)

앱 전체의 진동을 같은 기준으로 고르기 위한 규칙이다. 팀 공유용 설명은 노션 「햅틱(진동) 가이드」에 있고, 이 문서와 내용이 같다. 진동 이름이나 실제 진동을 바꾸면 둘을 같이 고친다.

코드는 `apps/web/src/shared/haptics`에 있다.

| 파일                 | 역할                                                                                                                              |
| -------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `haptic-kinds.ts`    | 진동 이름 6가지와 이름마다 플랫폼별 실제 진동. 느낌을 바꿀 땐 이 표만                                                             |
| `haptics.ts`         | `haptic(이름)` — 설정 확인, 녹음 중 막기, 같은 이름 30ms 연타 막기, 브릿지·폴백 전송. `muteHaptics()`로 막고 돌려받은 함수로 푼다 |
| `GlobalHaptics.tsx`  | 버튼·링크 누름에 `tap`을 자동으로 울리는 전역 리스너                                                                              |
| `press-area.ts`      | 누른 자리가 끌기 요소·스크롤 영역·그 밖 중 어디인지 판별                                                                          |
| `haptics-setting.ts` | 마이페이지 진동 켬/끔                                                                                                             |

## 진동 이름

화면 코드는 세기(light·medium)가 아니라 무슨 일이 일어났는지로 부른다.

| 이름        | 뜻                   | 쓰는 곳                                                                | 같이 나오는 화면 반응 | iOS       | Android |
| ----------- | -------------------- | ---------------------------------------------------------------------- | --------------------- | --------- | ------- |
| `tap`       | 눌렀다               | 버튼·링크·선택지·토글·탭 전환 (전역 자동)                              | 누른 색·크기 변화     | light     | light   |
| `tick`      | 값이 한 칸 바뀌었다  | 시간 휠, 글자 타이핑, 칩 자리 바뀜, 캐러셀 넘김, 말이 확정됨(들었어요) | 칸 이동·글자 나타남   | selection | light   |
| `success`   | 일이 잘 끝났다       | 정답, 저장·전송·등록 완료                                              | 체크·초록 표시        | success   | success |
| `celebrate` | 축하할 순간이다      | 스트릭 열매, 복습 전부 맞힘, 보상, 발음 통과, 학습 완료                | 폭죽·도장·동전        | success   | success |
| `warning`   | 막혔다, 다시 해 보자 | 발음 미통과, 무음, 입력 제한, 잠긴 기능                                | 흔들림·노란 안내      | warning   | warning |
| `error`     | 실패했다             | 오답, 녹음·전송·결제 오류                                              | 빨간 표시·오류 시트   | error     | error   |

- `success`와 `celebrate`는 지금 같은 진동이다. 앱 업데이트로 축하 전용 진동을 넣을 때 화면 코드를 고치지 않게 이름만 나눠 둔다.
- Android는 selection이 거의 안 느껴져 `tick`을 light로 울린다.

## 원칙

1. 진동은 혼자 오지 않는다. 같은 순간에 눈에 보이는 반응(색·애니메이션)이 있어야 한다. 진동은 설정·기기에 따라 꺼질 수 있다.
2. 평소엔 가볍게, 특별한 순간만 분명하게. 누름은 `tap` 하나, 리듬 있는 진동은 결과와 성취에만.
3. 막힘은 `warning`, 실패만 `error`. 다시 해 보면 되는 순간에 `error`를 쓰면 학습 의욕이 꺾인다.
4. 한 순간에 하나. 누름 `tap` 다음에 결과 진동이 이어서 온다. 같은 이름을 30ms 안에 두 번 부르면 하나만 울린다.
5. 녹음 중에는 울리지 않는다. 진동 소리가 녹음에 섞이면 음성 인식·발음 평가에 잡음이 된다. 대화 음성 인식(`useStt`)과 발음 녹음(`useSentenceRecorder`)이 녹음하는 동안 `muteHaptics()`로 막아 두므로, 화면 코드는 신경 쓰지 않아도 된다. 새 녹음 경로를 만들면 같은 방식으로 막는다.
6. 흔들림(`animate-shake`)은 `warning` 진동과 한 쌍이다.
7. 축하는 방금 해낸 순간에만. 이미 끝낸 화면을 다시 볼 때(완료 카드 다시 열기, 같은 날 두 번째 대화)는 울리지 않는다.
8. 동작 줄이기(reduced motion)와 진동은 따로다. 연출이 꺼져도 성취는 같으니 진동은 기다리지 않고 바로 울린다. 진동을 끄는 건 마이페이지 진동 설정이 한다.

## 버튼 누름 (전역 자동)

`button`, `a[href]`, `[role="button"]`, `summary`, `[data-haptic]`을 누르면 `GlobalHaptics`가 `tap`을 울린다.

| 누른 자리                                 | 언제 울리나                  | 울리지 않는 경우                                                |
| ----------------------------------------- | ---------------------------- | --------------------------------------------------------------- |
| 그 밖 (화면 고정 버튼, 짧은 화면)         | 닿는 순간                    | 없음                                                            |
| 스크롤 영역 (목록, 캐러셀, 긴 페이지)     | 손을 떼서 탭이 성립하는 순간 | 브라우저가 스크롤로 넘겨받음, 손가락이 움직이며 영역이 스크롤됨 |
| 끌기 요소 (`touch-action: none`, 퀴즈 칩) | 손을 떼서 탭이 성립하는 순간 | 5px 이상 끌었음                                                 |

어디서든 두 번째 손가락, 마우스 오른쪽·가운데 버튼, 키보드·코드 클릭, 누른 버튼 밖에서 뗀 클릭, 비활성 버튼(안쪽 요소 포함), `data-no-haptic` 안쪽은 울리지 않는다.

## 쓰는 법

| 버튼 종류                           | 할 일                                       |
| ----------------------------------- | ------------------------------------------- |
| 일반 버튼, 선택지, 토글, 탭 전환    | 없음 (`tap` 자동)                           |
| 누르면 결과가 나오는 버튼           | 결과 순간에 `haptic('success')` 등을 부른다 |
| 화면만 넘어가는 링크·목록 행        | `data-no-haptic`을 붙인다                   |
| 뒤로·닫기                           | 공통 헤더·모달에 붙어 있다                  |
| 직접 진동을 울리는 버튼 (알람 다짐) | `data-no-haptic`을 붙인다                   |

```tsx
import { haptic } from '@/shared/haptics';

haptic('celebrate'); // 폭죽이 터지는 순간 (애니메이션이 닿거나 끝나는 콜백에서)

<button data-haptic="tick">다음 칸</button> // 누름 진동을 다른 이름으로
<nav data-no-haptic>...</nav> // 이 안쪽은 누름 진동 없음
```

## 새 진동을 넣을 때

- [ ] 여섯 이름 중 하나로 골랐는가? 새 이름이 필요하면 이 문서와 `haptic-kinds.ts`부터 고친다
- [ ] 같은 순간에 같이 나오는 화면 반응이 있는가?
- [ ] 다시 해 보면 되는 순간에 `error`를 쓰지 않았는가?
- [ ] 이미 끝낸 화면을 다시 볼 때 축하가 또 울리지 않는가?
- [ ] 녹음 중에 울리지 않는가? (새 녹음 경로면 `muteHaptics()`로 막았는가?)
- [ ] 버튼 `onClick`에서 `tap`을 또 부르지 않는가? (전역이 이미 울린다)
- [ ] 화면만 넘어가는 버튼에 `data-no-haptic`을 붙였는가?

## 확인하는 법

- 단위 테스트: `postToNative`를 목으로 바꿔 보낸 진동을 확인한다 (`GlobalHaptics.test.tsx`). jsdom은 레이아웃이 없어 `scrollHeight`·`clientHeight`를 직접 정해 스크롤 영역을 흉내 낸다.
- 시뮬레이터·에뮬레이터: 진동이 실제로 나지 않는다. 셸 Debug 빌드의 Metro 로그에서 `[bridge:native] web -> native: HAPTIC` 줄 수로 울렸는지만 본다.
- 세기와 손 느낌: 실기기에서만 볼 수 있다.
